# ER Flow Tracker

A mobile-first React + Vite application for tracking ER patients, pending tasks, consult services, disposition, and room assignment.

## Run locally

1. Install Node.js 18 or newer.
2. Open a terminal inside this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Vite.

## Build for deployment

Run `npm run build`. The deployable site will be placed in `dist/`.

## Privacy

Use patient codes or initials only. Do not enter full names, complete MRNs, addresses, contact details, or other identifying patient information. Data is stored only in that browser's localStorage unless you modify the application.
